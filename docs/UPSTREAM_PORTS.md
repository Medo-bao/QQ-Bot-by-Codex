# 官方更新适配记录

核对日期：2026-11-02。上游：[tencent-connect/dsh-qqbot](https://github.com/tencent-connect/dsh-qqbot)，最新版本 0.5.5，提交 `a4a01fa9f122e187733fbd990c3d6a41e4d7e538`。

本次范围为最初采用的 `ee980be2b45dc868bb7ea58babc45775e4c2a871` 之后的 20 个上游提交。QQ Bot 当前软件版本仍为 0.0.5。

| 上游改动 | 适配结果 |
| --- | --- |
| 图片附件真实格式，`078c338` | 已移植。QQ 图片与网页下载识别 PNG、JPEG、GIF、WebP、BMP 的文件头，只修正不匹配的扩展名，不转码；未知格式保留原名。兼容 `image` 与 `image/*` 声明。 |
| 偏好文件写前合并，`e49dadf` | 已适配到 `sessions.json`。每次保存合并磁盘上其他会话，当前 key 按本次保存值更新；不同实例依次保存时不再以旧内存覆盖其他会话。损坏文件拒绝覆盖。当前没有删除会话记录接口，因此不引入删除墓碑。该合并不是跨进程事务锁。 |
| 原子临时文件隔离，`e49dadf` | 已移植。临时文件包含进程与随机 ID，以独占创建和重命名替换写入；失败清理自己创建的临时文件并报告错误。 |
| `/bot-me`，`96ad70a` | 已移植。返回真实消息发送者 OpenID，群聊附带群 OpenID，不创建 AI 回合；适用于当前访问规则允许的会话。帮助说明同步更新。 |
| 二维码失败降级，`0aa3524` | 已移植前端降级。图像请求或加载失败时隐藏裂图、保留绑定链接与手动入口，二维码刷新后恢复，旧异步结果不覆盖新二维码。本项目已将 qrcode 随产物打包，保留可用的模块加载方式。 |
| 绑定状态刷新，`04acada` | 已适配。服务端配置变化时更新未修改的设置表单；保留正在编辑的草稿，避免覆盖用户输入。 |
| 管理命令及审批鉴权，`0f050ec`、`7ffb1c3`、`000af47` | 已有等效或更严格路径：私聊和群聊消息在命令执行前均通过访问控制；白名单模式拒绝未列入的发送者。审批与提问绑定发起者、目标会话及本轮唯一 token，过期或转发卡片不能批准其他请求。开放模式仍按用户现有选择执行。 |
| 默认私聊开放，`d11acd3` | 不替换现有策略。保留本项目私聊白名单、群聊关闭的初始默认值，以及用户已保存的实际访问设置。 |
| 符号链接路径校验，`000af47` | 已有真实路径检查。发送目录和目标都经 realpath 判断；完全访问模式继续按已有授权将外部文件归档后发送。 |
| 统一工作目录，`70371b3`、`7ffb1c3` | 已有 Codex 工作目录与按机器人、会话归档的存储目录，保留用户配置。 |

| 恢复失败与并发创建，`e57f51a`、`7f07be9` | 已有同会话队列及原生恢复流程；恢复失败不会被吞掉后重建空上下文，错误可见，原记录保留。 |
